HTTPS / Secure Context

OpenClaw Control UI erfordert einen secure context (HTTPS, localhost oder file://). Im reinen HA-Ingress über HTTP wird der WebUI-Tab daher als externer Link geöffnet. Im lan_https-Modus (selbstsigniertes Zertifikat im lokalen Netz) funktioniert der iframe-Tab.
